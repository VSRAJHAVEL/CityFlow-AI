About CityFlow AI.

Decentralized Multi-Agent Reinforcement Learning (MARL) for urban traffic optimization with zero-wait emergency wave preemption and autonomous collision mitigation.

Stack: Python 3.11 • FastAPI • ES6 Canvas
functions

Mathematical Reinforcement Learning Model

Each of the 16 intersections is modeled as an independent Markov Decision Process (MDP) agent with observation state s = [q_N, q_S, q_E, q_W] and action set A = {NS-Green, EW-Green}.

Bellman Value Iteration Update:
Q(s, a) ← Q(s, a) + α · [ R(s, a) + γ · max_{a'} Q(s', a') − Q(s, a) ]
Where learning rate α = 0.12 and discount factor γ = 0.95.
Collaborative Neighborhood Reward Function:
R(s, a) = −( q_local² + 0.30 · q_neighbor_load )
Penalizes local queue quadratic backlog while discouraging spillback into adjacent intersection sectors.
account_tree

Deterministic BFS Green Wave Algorithm

Emergency transit guarantees zero starvation by pre-empting reinforcement learning policies along the shortest planar route:

  • Queue Graph Search: Explores the 4x4 adjacency graph in O(V + E) microsecond time.
  • Forced Phase Lock: Intersections along the corridor set forced = direction, ensuring continuous green wave clearance.
  • Automatic Resumption: Once the emergency asset clears a junction, the local Q-agent seamlessly reclaims signal control without state loss.
Zero-Dependency Engineering Philosophy:

Built entirely in Python 3.11, FastAPI, and Vanilla ES6 Canvas without SUMO, Docker, or heavy neural networks. Produces sub-5ms simulation step latency and 60 FPS hardware-accelerated rendering on standard consumer hardware.
